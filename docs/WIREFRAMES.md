## Home (vertical stack)

1. **Hero** — full viewport, headline, CTA ×2
2. **Artists** — 2-col mobile / 4-col desktop grid, "Show all"
3. **New music** — horizontal scroll cards (pinned on desktop)
4. **Producers & writers** — avatar row
5. **Our universe** — 3 cards (video / podcast / studio)
6. **Partners** — logo strip
7. **About teaser** — mission line + link
8. **Newsletter** — email field + provider link
